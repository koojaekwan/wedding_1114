# 💌 구재관 ♥ 이채희 모바일 청첩장

2026년 11월 14일(토) 오후 5시 50분, 호텔수성 수성스퀘어 2층 아이비홀에서 열리는 결혼식을 위해 제작한 모바일 웹 청첩장입니다.
HTML / CSS / JavaScript만으로 만든 정적 웹페이지이며, GitHub Pages로 배포되어 있습니다.

🔗 배포 주소: https://koojaekwan.github.io/wedding_1114/

## 📌 주요 기능

- **메인 커버**
  신랑·신부 이름, 예식 일시, D-Day(결혼식까지 남은 기간) 카운터를 대표 사진과 함께 보여줍니다.

- **초대 인사말 & 가족 관계**
  인사말 문구와 함께 신랑측·신부측 혼주 성함을 가족관계도 형태로 정리해 보여줍니다.

- **예식 일자 / 실시간 카운트다운**
  11월 캘린더에서 예식일을 하이라이트로 표시하고, 예식까지 남은 시간을 일·시·분·초 단위로 실시간 갱신합니다.

- **오시는 길**
  네이버 지도 API를 연동해 예식장 위치를 지도에 표시하고, 네이버 지도 길찾기로 바로 연결됩니다. 자가용·대중교통 이용 안내 문구도 함께 제공합니다.

- **안내사항**
  연회장 이용 시간, 주차 안내(대수/무료 시간) 등 하객이 알아야 할 정보를 안내합니다.

- **갤러리**
  웨딩 사진을 그리드로 보여주며 "사진 더보기" 버튼으로 추가 사진을 펼쳐볼 수 있고, 사진 클릭 시 좌우 넘기기가 가능한 라이트박스(확대보기) 모달을 제공합니다.

- **마음 전하실 곳 (계좌 안내)**
  신랑측/신부측 계좌 정보를 아코디언(토글) 형태로 감춰두고, 필요할 때 펼쳐볼 수 있습니다. 각 계좌번호는 버튼 클릭 한 번으로 클립보드에 복사되며, 복사 완료 시 화면 하단에 토스트 메시지가 표시됩니다.

- **배경음악 재생**
  화면 우측(또는 지정 위치)의 플로팅 버튼으로 배경음악을 재생/일시정지할 수 있습니다.

- **청첩장 링크 공유**
  하단 "청첩장 링크 복사" 버튼으로 페이지 URL을 클립보드에 복사해 카카오톡 등으로 간편하게 공유할 수 있습니다.

- **스크롤 등장 애니메이션**
  각 섹션 요소에 `reveal` 클래스와 지연 시간을 적용해, 스크롤할 때 자연스럽게 나타나는 연출을 구현했습니다.

## 🛠️ 기술 스택

- **HTML5 / CSS3** – 시맨틱 마크업 + 커스텀 웹폰트(Cormorant Garamond, Noto Serif KR, Noto Sans KR)를 활용한 반응형(모바일 우선) 레이아웃
- **Vanilla JavaScript** – 카운트다운, 갤러리 라이트박스, 계좌 복사, 음악 재생, 공유 등 인터랙션 구현 (별도 프레임워크 없음)
- **네이버 지도 API (Naver Maps API v3)** – 오시는 길 지도 표시
- **GitHub Pages** – 정적 사이트 배포

## 📁 폴더 구조

```

```

## 🚀 로컬에서 실행하기

별도 빌드 과정이 필요 없는 정적 페이지입니다.

```bash
git clone https://github.com/koojaekwan/wedding_1114.git
cd wedding_1114
```

이후 `index.html`을 브라우저로 열거나, 로컬 서버를 띄워 확인합니다.

```bash
# 예: Python 내장 서버 사용
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

> 네이버 지도 등 일부 기능은 파일을 직접 열기(file://)보다 로컬 서버(http://)로 실행할 때 더 안정적으로 동작합니다.

## ✏️ 커스터마이징 가이드

다른 예식에 맞게 재사용하고 싶다면 아래 항목을 수정하면 됩니다.

| 항목 | 위치 |
| --- | --- |
| 신랑·신부 이름, 예식 일시, 장소 | `index.html` 상단 `<meta>` 태그 및 `#main-cover`, `#wedding-calendar` 섹션 |
| 혼주 이름, 가족 관계 | `#intro-greeting`의 `.family-tree` |
| 지도 위치, 길찾기 링크 | `#wedding-location`의 `#map`, `.navigation-links` (네이버 지도 API 키 포함) |
| 안내사항 문구 | `#notice-sections`의 `.notice-list` |
| 갤러리 사진 | `#gallery-section`의 `pic/` 이미지 경로 |
| 계좌 정보 | `#gift-accounts`의 `.account-details-row`, `data-copy` 속성 |
| 배경음악 | `maybe.mp3` 파일 교체 |

## 🌐 배포

`main` 브랜치를 GitHub Pages 소스로 지정해 배포합니다. 배포 후에는 `index.html`의 `og:image`, `og:url`을 실제 절대 경로로 유지해야 카카오톡 등 메신저에서 링크 미리보기가 정상적으로 노출됩니다.
